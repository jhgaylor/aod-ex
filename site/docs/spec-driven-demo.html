How the planning agent fans out
Every sprite gets the bundled aod skill and AOD_BASE_URL/AOD_TOKEN in env. The planning agent calls back to your AoD instance to spawn children:

# To spawn a sub-agent, POST to $AOD_BASE_URL:
curl -X POST $AOD_BASE_URL/api/conversations \
  -H "Authorization: Bearer $AOD_TOKEN" \
  -d '{
    "agent_id": "spec-implementer",
    "prompt": "Implement AUTH-001...\n\n<spec content>"
  }'

# Then poll or stream until done:
curl $AOD_BASE_URL/api/conversations/$ID/stream
Planning agent prompt
You are a planning agent. When given a feature description:

1. Decompose it into 2-5 atomic specs, each with a
   stable ID and clear acceptance criteria.
2. Write each spec as a feature.yaml and commit it
   to specs/ in the repo.
3. Use the aod skill to spawn one implementation
   agent per spec in parallel.
4. Wait for all agents to complete.
5. Run `acai coverage` and report which criteria
   are satisfied. Re-trigger any agent with gaps.
6. Open a final PR summarizing the implementation.
Runtime arbitrage
Because the spec is the contract — not the prompt — each child agent can use a different runtime. The planning agent chooses based on task type:
AUTH-001 Complex stateful logic claude-sonnet-4-6
AUTH-002 OAuth boilerplate codex
AUTH-003 Token / session logic claude-sonnet-4-6

Skills — what the agent knows
Markdown files mounted into the sprite before the first turn

Skills are SKILL.md files written to the sprite before the conversation starts. The agent reads them as part of its system context. Two shapes: inline (content in the agent definition) or github (fetched via skills.sh CLI).

Spec commit → agent trigger
# .github/workflows/implement-specs.yml
on:
  push:
    paths: ['specs/**/*.yaml']

jobs:
  implement:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 2 }

      - name: Fire agent per changed spec
        env:
          AOD_BASE_URL: ${{ secrets.AOD_BASE_URL }}
          AOD_TOKEN: ${{ secrets.AOD_TOKEN }}
          AGENT_ID: ${{ secrets.SPEC_IMPLEMENTER_AGENT_ID }}
        run: |
          git diff --name-only HEAD~1 HEAD -- 'specs/**/*.yaml' \
          | while read f; do
            id=$(grep '^id:' "$f" | awk '{print $2}')
            body=$(cat "$f")
            curl -s -X POST $AOD_BASE_URL/api/conversations \
              -H "Authorization: Bearer $AOD_TOKEN" \
              -H 'content-type: application/json' \
              -d "{\"agent_id\":\"$AGENT_ID\",\
                   \"prompt\":\"Implement $id.\\n\\n$body\"}" \
            | jq -r '"Started " + .id + " for " + "'$id'"'
          done
Coverage check on PR
# .github/workflows/coverage.yml
on: [pull_request]

jobs:
  coverage:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pip install acai-sh
      - name: Check spec coverage
        run: |
          acai coverage \
            --spec-dir specs/ \
            --source-dir lib/ \
            --fail-under 100   # block merge if any criteria unmet

Fan-out: run all specs in parallel
import asyncio, httpx, yaml
from pathlib import Path

AOD_BASE = "http://localhost:4000"
TOKEN = "your-admin-token"
AGENT_ID = "spec-implementer-id"

async def run_spec(client, spec_path: Path):
    spec = yaml.safe_load(spec_path.read_text())
    resp = await client.post(
        f"{AOD_BASE}/api/conversations",
        headers={"Authorization": f"Bearer {TOKEN}"},
        json={
            "agent_id": AGENT_ID,
            "prompt": f"Implement {spec['id']}.\n\n{spec_path.read_text()}",
        },
    )
    conv_id = resp.json()["id"]
    print(f"Started {conv_id} for {spec['id']}")

    # Stream until done
    async with client.stream(
        "GET", f"{AOD_BASE}/api/conversations/{conv_id}/stream",
        headers={"Authorization": f"Bearer {TOKEN}"},
    ) as stream:
        async for line in stream.aiter_lines():
            if line.startswith("data:"):
                print(f"  [{spec['id']}]", line[5:].strip())

async def main():
    specs = list(Path("specs").rglob("*.yaml"))
    async with httpx.AsyncClient(timeout=300) as client:
        await asyncio.gather(*[run_spec(client, s) for s in specs])

asyncio.run(main())
